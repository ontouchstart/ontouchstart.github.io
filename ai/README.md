# AI Friendly Software Engineering

Engineering is problem solving, Software Engineering is solving software problems or solving problems with software.
AI Friendly Software Engineering is solving AI caused software problems or solving software problems with AI.

## Problems can be solved by software

Fundamentally they are data problems: data generation, collection, storage, transmission, and transformation. 

## Software problems

Software problems are tooling problems. Software should perform specific tasks. Problems related to Software Development Life Cycle (SDLC) are software problems. Since we use software in SDLC, we can also use software to solve software problems. So the border is kind of fuzzy here.

## AI is nondeterministic automation

Regardless of implementations or service provider, fundamentally AI is just [nondeterministic](https://en.wikipedia.org/wiki/Nondeterministic_algorithm) automation. In this context, AI friendly software engineering faces new opportunities and challenges.

First let's take a look at automation. Before AI, the main purpose of computer is to use algorithms to accomplish steps of well defined data processing tasks. In principle, all these tasks can be accomplished by [human computers](https://en.wikipedia.org/wiki/Computer_(occupation)). The underlying mathematical principle is [Turing Machine](https://en.wikipedia.org/wiki/Turing_machine). Physical computing systems only make the process faster and handle more data. No matter how big the data, how complex the computing system, under the same context, same input always generate exact the same output. That is the meaning of deterministic automation. If you send the same query to a database, the output is always the same, unless the database itself changed between queries. 

AI is a different kind of "database", where the query is processed by a nonderministic machine and the output is a random variable that has the probability "defined" by the system. The "definition" is not an algorithm like normal programs, or some simple [random number generator](https://en.wikipedia.org/wiki/Random_number_generation). It is a random number generator in the sense that the probability was "defined" by the training and inference processes (data + compute). And this whole process is highly complex and automated. That is why we call it nondeterministic automation.
