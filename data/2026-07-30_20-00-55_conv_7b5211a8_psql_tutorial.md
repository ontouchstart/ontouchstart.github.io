# 🟢 Module 1: The Basics (The "Where am I?" Phase)

Before you type a single command, understand the difference between **SQL** and **psql**:
*   **SQL**: The universal language used to talk to the database (e.g., `SELECT * FROM users;`).
*   **psql**: The command-line tool that allows you to type those SQL commands and see the results. It also has "meta-commands" (starting with a backslash `\\`) that only work inside the `psql` tool.

### 1. Connecting to PostgreSQL
Open your terminal and type:
```bash
psql -d postgres
```
*(This connects you to the default "postgres" database. If your username is different, you might need `psql -U username -d postgres`.)*

### 2. Essential Navigation Commands
Once inside the `psql` prompt (which looks like `postgres=#`), use these:

*   **`\\?`** : Displays a list of all `psql` internal commands.
*   **`\\h`** : Shows help for SQL commands (e.g., `\\h SELECT`).
*   **`\\q`** : **Quit/Exit** the `psql` console.
*   **`\\c [db_name]`** : **Connect** to a different database.

# 🟡 Module 2: Exploring the Database (Meta-Commands)

When you are exploring a new database, these are the "map" commands you will use 90% of the time.

| Command | What it does |
| :--- | :--- |
| **`\\l`** | **List** all available databases. |
| **`\\dt`** | **Display Tables** in the current database. |
| **`\\d [table_name]`** | **Describe** a table (shows columns, types, and indexes). |
| **`\\dn`** | List all schemas. |
| **`\\df`** | List functions. |
| **`\\dv`** | List views. |
| **`\\conninfo`** | Show current connection information. |

# 🟠 Module 3: Creating the Foundation (DDL - Data Definition)

Now we move into standard SQL. **Note: In SQL, almost every command must end with a semicolon `;` or it won't run!**

### 1. Creating a Database & Table
```sql
-- Create a database
CREATE DATABASE store_db;

-- Connect to it (psql command)
\\c store_db

-- Create a table
CREATE TABLE products (
    id SERIAL PRIMARY KEY,
    name TEXT NOT NULL,
    price NUMERIC(10, 2),
    stock_count INTEGER
);
```

### 2. Altering Tables
If you made a mistake and need to add a column:
```sql
ALTER TABLE products ADD COLUMN category TEXT;
```

# 🔴 Module 4: Manipulating Data (DML - Data Manipulation)

This is where you interact with the actual information.

### 1. Inserting Data
```sql
INSERT INTO products (name, price, stock_count, category) 
VALUES ('Laptop', 999.99, 10, 'Electronics'),
       ('Mouse', 25.00, 50, 'Accessories');
```

### 2. Querying Data (The "Read" part of CRUD)
*   **Select everything:** `SELECT * FROM products;`
*   **Filter results:** `SELECT * FROM products WHERE price > 50;`
*   **Limit results:** `SELECT * FROM products LIMIT 5;`
*   **Order results:** `SELECT * FROM products ORDER BY price DESC;`

### 3. Updating and Deleting
*   **Update:** `UPDATE products SET price = 899.99 WHERE name = 'Laptop';`
*   **Delete:** `DELETE FROM products WHERE stock_count = 0;`

# 🟣 Module 5: Pro-Tips for `psql` Power Users

Once you get comfortable, these three commands will make your life much easier:

1.  **`\\x` (Expanded Display):** If a table has many columns, the output can look messy in the terminal. Type `\\x` to toggle "Expanded Mode." It turns rows into a vertical list (easier to read).
2.  **`\\timing`:** This turns on a timer so you can see exactly how many milliseconds a query takes to run.
3.  **`\\watch [seconds]`** : This repeats your last query every X seconds. Great for watching data change in real-time.
