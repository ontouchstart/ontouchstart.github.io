*   **The Validator (Testing):** The system must attempt to execute the newly created code. If it throws an error, the error message is fed back into the Architect to "fix" the code.
*   **The Integrator (Memory):** Once a tool passes validation, it is saved to a permanent directory and added to the Capability Map. The machine now "knows" how to do that task.

### 3. How to "Teach" it?
The "teaching" happens through **Reinforcement and Feedback**:

1.  **Success Feedback:** When the `Validator` successfully runs a new tool, the machine "retains" that tool.
2.  **Failure Feedback:** When the `Validator` fails, the machine receives the stack trace. You "teach" it by making the machine read that stack trace and try to rewrite the tool.
3.  **Recursive Expansion:** As the `Capability Map` grows, the machine can start using its *newly built* tools to help it build *even more complex* tools.

### Summary of the "Meta" Step
To make this work, the machine must be able to:
1.  **Write code.**
2.  **Execute code.**
3.  **Read error messages.**
4.  **Iterate** until the error message disappears.

By automating these four steps, you create a machine that can autonomously expand its own utility.
