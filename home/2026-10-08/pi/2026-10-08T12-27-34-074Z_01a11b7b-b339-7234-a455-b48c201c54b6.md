To run the `bun` command with subcommands and options using `nix run ./bun`, you should use the `--` separator. This tells Nix to stop parsing arguments for `nix run` and pass everything following the separator directly to the `bun` binary.

Here are some examples:

**1. Running a subcommand (e.g., `bun install`):**
```bash
nix run ./bun -- install
```

**2. Running a script with arguments (e.g., `bun run -- some-script.ts`):**
```bash
nix run ./bun -- run -- some-script.ts
```

**3. Checking the version:**
```bash
nix run ./bun -- --version
```

**4. Adding a dependency:**
```bash
nix run ./bun -- add <package-name>
```

**Why use `--`?**
While `nix run` often passes trailing arguments to the binary automatically, using `--` is the standard and safest way to ensure that flags intended for `bun` (like `-v` or `--help`) are not accidentally interpreted as flags for the `nix run` command itself.
