    *   **Mechanism:** The `flake.nix` defines a development shell that includes `rustc`, `cargo`, `curl`, `sqlite`, `fossil`, `pkg-config`, and `openssl`.
    *   **Isolation:** By using `nix develop`, we ensure that the agent always works with the exact same versions of system libraries. This eliminates "missing shared library" errors that often plague automated builds.
    *   **Workspace Cleanliness:** The `shellHook` in `flake.nix` redirects `CARGO_HOME` and `CARGO_TARGET_DIR` to `/tmp`. This ensures that the agent's workspace remains clean, as build artifacts and downloaded crates are stored in a temporary directory.

2.  **Cargo Layer (Project Environment):**
    *   **Role:** Manages project-specific Rust dependencies and the build lifecycle.
    *   **Mechanism:** Cargo handles the crate dependency graph (e.g., `curl`, `openssl-sys`) and orchestrates the compilation of the Rust source code.
    *   **Integration:** Because Nix provides `pkg-config` and the actual system libraries (`libcurl`, `openssl`), Cargo's build scripts can successfully locate and link against these libraries during the compilation of `curl-sys` and other system-linked crates.

### Key Benefits for Agentic Coding

*   **Hermeticity:** The agent can be confident that any command run via `nix develop --command <cmd>` will have access to the required tools and libraries without needing to manually install anything on the host system.
*   **Reproducibility:** The entire environment is defined in code (`flake.nix`). If an agent needs to start a new project or move to a new machine, it simply runs `nix develop`.
*   **Simplified Dependency Management:** The "Double Container" solves the classic "C-library dependency hell" in Rust. Nix handles the "outside" (system libraries) and Cargo handles the "inside" (Rust crates).
*   **Ephemeral Builds:** Redirecting Cargo's home and target directories to `/tmp` allows the agent to perform multiple builds without accumulating large amounts of persistent data or conflicting with previous runs.

### Summary of Commands Used
*   `nix develop --command cargo --version`: Verifies the toolchain in the Nix shell.
*   `nix develop --command cargo init --bin my_app`: Initializes a new Rust project within the Nix environment.
*   `nix develop --command sh -c "cd my_app && cargo build"`: Compiles the project, demonstrating successful linking of system libraries provided by Nix.
