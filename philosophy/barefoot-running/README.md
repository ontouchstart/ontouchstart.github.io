# Philosophy of Barefoot Running

Running on natural and artificial surfaces without artificial support is a way to learn full body motion with only sensory and muscle memory. It is a non-linguistic activity at three levels: neuromuscular, biochemical, and mental.

When run with companions with active conversation, there are linguistic moments in the form of verbal communication in addition to body languages. In solo run, there might be moments of inner dialogues in addition to non-linguistic thoughts. Sensory input plays dominant role in the activity of barefoot running.

Nevertheless, barefoot running is one of the mentally demanding activities that require little linguistic or physical efforts. We can analyze this activity from philosophic standpoint with or without language. This draft note is an attempt to start the linguistic part of the analysis.
