# Introduction (or how I get here)

I built a Rust notebook built with [mdBook](https://rust-lang.github.io/mdBook) 
to embed an interactive canvas drawing app implemented in WASM code written by hand, i.e., in byte code.
It was maintained as a public GitHub repo and deployed to both [GitHub Pages](https://docs.github.com/en/pages) and [Cloudflare Pages](https://pages.cloudflare.com) via GitHub actions and an example of edge computing in WASM.

I showed that notebook to the managing director of a tech consulting company and blew his mind. 

I was hired back to professional software development. So I stopped hacking openly on GitHub, deleted all my repositories (including that Rust notebook) except a few public archives I did for a non-profit organization. I haven't looked at them since the 2019 New York City Marathon.

## What is this notebook then?

This notebook is my new exploration of the process of software development with modern toolchains in 
[Python](https://docs.astral.sh/uv) and [Rust](https://doc.rust-lang.org/cargo). 

The investigation in this notebook will be more on **how** to do things with these tools other than **what** to do. 
If I am hired to do things professionally, it would be more about **what** than **how**.

This is notebook of ideas, not a product. 
I will not maintain it professionally because it is not worth it. 
**Please do not use any part of it as a dependency in your project**.

This is not an educational or promotional (portfolio) web site either. I have no interest to teach anyone or explain 
what I did, how I did it and why I did it. Every page, module and line of code has its purpose I might or might not explain.
